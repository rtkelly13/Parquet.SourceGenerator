# Call-graph allowlist (#252) — every cycle the gates would otherwise reject, with
# the reason it is legitimate. Same philosophy as CodeMetricsConfig.txt and
# src/api/seams.txt: exceptions are counted, named, and meant to come off.
#
# Formats:
#   SELF	<exact	method id> <reason>       direct self-recursion
#   SCC	 <id | id	| ...> <reason>         a multi-node strongly-connected component
#
# The TargetParser compound-model cycle is the parser walking a nested [ParquetSerializable]
# tree: CollectMembers -> CollectMember -> TryCollectCompoundMember -> BuildCompoundModel ->
# CollectMembers (one level down), with BuildNestedElementModel handling list elements and
# map values on the same descent. Parquet schemas are trees; recursion is the correct shape
# (#176/#182's design), and the containment path + MaxCompoundDepth bound it. This is the
# issue's explicitly blessed case ("the compound model parser is genuinely recursive over a
# tree") — not mutual recursion across components.

SELF	Parquet.SourceGenerator.Emitter.Compound.CompoundMapping.EmitLadder/(StringBuilder,LeafColumn,string,int,string,string)	Definition-ladder shredding walks one level of the Parquet definition tree per call (#185); depth is bounded by the schema the parser already capped.
SELF	Parquet.SourceGenerator.Emitter.Compound.CompoundSchema.GetFieldCreationExpression/(PropertyModel,string)	Struct fields contain structs; the field creation recurses to emit the nested DataField tree.
SELF	Parquet.SourceGenerator.Emitter.Compound.EmissionPlan.WalkStruct/(PropertyModel,StructNode,int,int[],int,bool[],bool[],string[],List<LeafColumn>,List<StructNode>)	The compound plan walk follows the child tree of a struct member; the recursion IS the traversal.
SCC	Parquet.SourceGenerator.Parser.TargetParser.BuildCompoundModel/(PropertyKind,ITypeSymbol,string,ITypeSymbol,string,int,bool,ParquetApiLevel,string,Location,List<DiagnosticInfo>,HashSet<INamedTypeSymbol>,int,CompoundKinds,bool) | Parquet.SourceGenerator.Parser.TargetParser.BuildNestedElementModel/(ITypeSymbol,string,ParquetApiLevel,string,string,Location,List<DiagnosticInfo>,HashSet<INamedTypeSymbol>,int,CompoundKinds,bool) | Parquet.SourceGenerator.Parser.TargetParser.CollectMember/(ISymbol,MemberScope,MemberSink) | Parquet.SourceGenerator.Parser.TargetParser.CollectMembers/(INamedTypeSymbol,MemberScope,MemberSink) | Parquet.SourceGenerator.Parser.TargetParser.TryCollectCompoundMember/(ISymbol,ITypeSymbol,ITypeSymbol,ColumnOptions,bool,Location,MemberScope,MemberSink)	The #176 compound parser descending a nested-model tree; bounded by MaxCompoundDepth and the containment path (PARQ012/PARQ013). One module, tree recursion — the issue's blessed case.
