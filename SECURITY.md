# Security Policy

## Supported Versions

Only the latest published version of **Parquet.SourceGenerator** receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |
| < 0.0.1 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **Parquet.SourceGenerator**, please report it privately rather than opening a public issue.

### How to Report
- Email details to the repository maintainer or use GitHub Private Vulnerability Reporting on the repository.
- Include steps to reproduce, sample C# code, or a minimal reproduction repository if possible.

### Our Commitment
- We will acknowledge receipt of your report within **48 hours**.
- We will provide an estimated timeline for remediation and keep you updated throughout the fix process.
